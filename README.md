# Calorie Burnt Prediction using Machine Learning

This project predicts the number of calories burned during exercise using Machine Learning techniques. The model is trained on exercise and calorie-related data such as age, gender, body measurements, exercise duration, heart rate, and body temperature.


# Project Overview

The goal of this project is to build a regression model that can accurately estimate calories burned based on physical and exercise-related parameters.

This project demonstrates:

->Data preprocessing

->Exploratory Data Analysis (EDA)

->Data visualization

->Feature engineering

->Model training and evaluation

->Prediction using Machine Learning


# Dataset Information

The project uses two datasets:

1.exercise.csv

2.calories.csv

These datasets are combined to create the final training dataset.


# Features Used
->Gender

->Age

->Body Temperature

# Target variable
-> Calories Burnt
